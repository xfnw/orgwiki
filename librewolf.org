#+TITLE: libre woof

librewolf is a fork of firefox that is somewhat privacy focused

* url bar overzealously searching
enable ~browser.fixup.dns_first_for_single_words~ in about:config to
make it check for hostnames instead of forcing them to be searches

#+begin_src javascript :tangle user.js
user_pref("browser.fixup.dns_first_for_single_words", true);
#+end_src

* url bar hiding protocol
turn off ~browser.urlbar.trimURLs~ in about:config

#+begin_src javascript :tangle user.js
user_pref("browser.urlbar.trimURLs", false);
#+end_src

* space beside url bar
to remove the wasted space, right click on them and go to Customize
Toolbar, then you can right click on the same place again and Remove
from Toolbar

not sure why this requires being in the customizing toolbar mode, the
list all tabs button has an option to remove it without being in the
customizing mode...

#+begin_src javascript :tangle user.js
user_pref("browser.uiCustomization.state", "{\"placements\":{\"widget-overflow-fixed-list\":[],\"unified-extensions-area\":[],\"nav-bar\":[\"back-button\",\"forward-button\",\"stop-reload-button\",\"vertical-spacer\",\"urlbar-container\",\"downloads-button\",\"fxa-toolbar-menu-button\",\"reset-pbm-toolbar-button\",\"ublock0_raymondhill_net-browser-action\",\"unified-extensions-button\"],\"toolbar-menubar\":[\"menubar-items\"],\"TabsToolbar\":[\"tabbrowser-tabs\",\"new-tab-button\",\"customizableui-special-spring4\"],\"vertical-tabs\":[],\"PersonalToolbar\":[\"personal-bookmarks\"]},\"seen\":[\"reset-pbm-toolbar-button\",\"ublock0_raymondhill_net-browser-action\",\"developer-button\",\"screenshot-button\"],\"dirtyAreaCache\":[\"unified-extensions-area\",\"nav-bar\",\"vertical-tabs\",\"toolbar-menubar\",\"TabsToolbar\",\"PersonalToolbar\"],\"currentVersion\":26,\"newElementCount\":4}");

* dark theme not working
the ~ResistFingerprinting~ option intentionally breaks
~prefers-color-scheme~ :(

#+begin_chat vulpine/eepy
at least it actually tells you this in the settings now, instead of
just silently not working...
#+end_chat

#+begin_src javascript :tangle user.js
user_pref("privacy.resistFingerprinting", false);
#+end_src

* shut up about enabling drm
turn off ~browser.eme.ui.enabled~ in about:config

#+begin_src javascript :tangle user.js
user_pref("browser.eme.ui.enabled", false);
#+end_src

* give me back my rectangles
i thought proton was bad, but mozilla has against all odds managed to
make something even worse. the new 'we made everything round and gave
everything a gradient so it looks like something an llm shat out'
theme can be avoided by turning off ~browser.nova.enabled~ in
about:config

#+begin_src javascript :tangle user.js
user_pref("browser.nova.enabled", false);
#+end_src

* extra settings i like
- disable Use smooth scrolling
- enable Always show scrollbars

#+begin_src javascript :tangle user.js
user_pref("general.smoothScroll", false);
user_pref("widget.gtk.overlay-scrollbars.enabled", false);
#+end_src

* ui density
firefox has a Window Density option in the Appearence settings to make
tabs and stuff nice and smol. not sure why this is missing from
librewolf's settings, but this option can be still be set with
~browser.uidensity~ in about:config anyways

#+begin_src javascript :tangle user.js
user_pref("browser.uidensity", 1);
#+end_src
